# 02 - 功能与预期清单

> 定位：dsh-claw-space 的**实际交付形态 + 用户预期对照 + 后期规划**的唯一入口文档（docs 目录仅此一份）。
> 数据截至 2026-10-03（v0.2.0，多魂并行交付）。历史设计文档与探针记录已清理，机制结论浓缩在 2.1 节。

---

## 一、核心概念

| 概念 | 定义 |
|---|---|
| 常驻 workspace | `~/.dsh/openclaw/`，插件固定读这里，跨会话、跨 cwd 对所有 agent 生效 |
| 物理生效文件 | 根目录的 md 文件永远是「生效真相」；`personas/` 是人设库存。agent 用原生工具改根目录文件 = 改生效内容 |
| 单魂 / 多魂 | 根目录三件 = 全局默认魂（单魂）；会话可用 `/user` 把自己绑到库存人设（多魂，§2.6），绑定的会话不受全局切换影响 |
| 文件族 | IDENTITY.md / USER.md / TOOLS.md / AGENTS.md / MEMORY.md / HEARTBEAT.md / memory/*.md / inject.md（SOUL 已移除，2026-10-03 布局拍板） |

## 二、已实现功能

### 2.1 常驻注入（host scope，一次注册全局生效）

| 文件 | 注入方式 | 段名 | order | 生效条件 |
|---|---|---|---|---|
| IDENTITY.md | 系统提示词 section | `openclaw:identity` | 0 | 总是（AI 的人设）；绑定会话改读库存 |
| USER.md | 系统提示词 section | `openclaw:user` | 1 | 总是（对用户的描述）；绑定会话改读库存 |
| TOOLS.md | 系统提示词 section | `openclaw:tools` | 2 | 总是 |
| AGENTS.md | 系统提示词 section | `openclaw:agents` | 3 | 总是（与官方 dsh-agent-instructions 读的 cwd AGENTS.md 互不重复） |
| MEMORY.md | context | `openclaw:memory` | 70 | **仅主会话**（text 回调读 `args[0].agent` 判定；无 agent 场景不注入） |
| memory/*.md | context | `openclaw:daily` | 80 | 最近 2 篇（可配），每篇超 8000 字符截断 |
| HEARTBEAT.md | context | `openclaw:heartbeat` | 120 | 有实际任务才注入（空文件/纯注释不注入） |
| inject.md [system] 块 | section | `gw-inject:<标题>` | 默认 40 | 块级启停 |
| inject.md [context] 块 | context | `gw-inject:<标题>` | 默认 125 | 同上 |

- 注入标签带**绝对路径**，agent 用 DSH 原生 read/write/edit 即可查看与修改文件；系统提示词四段（section）正文首行另有 `<!-- claw-space 来源: <绝对路径> ｜ 编辑此文件即修改本段 -->` 标注（绑定会话标库存路径，未绑定标根目录）
- 所有注册段均 `interpolate: false`——用户文件里的 `{{xxx}}` 不走官方变量插值（未注册变量会 throw 炸掉 assemble）
- 每文件注入上限（perFileLimits）：IDENTITY 4000 / USER 4000 / TOOLS 4000 / AGENTS 4000 / MEMORY 6000 / daily 每篇 8000 字符；超限截断并标注完整路径
- 热加载：`fs.watch` 递归监听整个 openclaw 目录，150ms 防抖；改文件 / 切人设 / agent 改文件统一收敛，内容不变时官方投影自动去重
- 首启脚手架：目录缺失自动创建（只建不覆盖）
- **机制实测结论（M1 探针，2026-10-03）**：真实请求时 section/context 的 text 回调收到 `args[0] = {agent}`（`agent.session.header` 可达 → mainOnly 判定依据）；无 agent 的全局装配预览传入空对象，故 MEMORY 此时返回空串；官方段与本插件段 order 混排实测无碰撞（同 order 按注册顺序稳定排列）；`ctx.get("agents")` 在 0.2.0-rc.2 可用不抛错

### 2.2 人设切换

- 范围：**只动 IDENTITY / USER 两件**（2026-10-03 布局拍板，SOUL 移除）；MEMORY / HEARTBEAT / daily / TOOLS / AGENTS 恒全局
- 面板「切换」改的是**全局默认魂**（根目录三件）；已用 `/user` 绑定的会话不受影响（§2.6）
- 操作（全部面板驱动，模型无切换入口）：
  - **切换**：当前三件套备份回 `personas/<旧>/` → 新库存三件换入根目录（缺失跳过并提示）→ 写 `.current` → 热刷新，当前会话下一轮换魂
  - **新建**：空模板（不从当前拷贝）；**删除**：二次确认；删除当前人设的入口已禁用（先切换再删）
- 文件区有未保存改动时点切换，先弹确认防静默丢失
- 切换是用户操作，**不注册为模型可调用工具**（防模型自行换魂）

### 2.3 自由注入块（inject.md）

- 数据文件：`~/.dsh/openclaw/inject.md`（旧位置自动迁移）；`## [system|context] 标题` 分块，中英元数据别名，与旧数据字节兼容
- [context] 走官方投影通道（不重发、旧快照作废）；[system] 受 MIN_ORDER=0 约束
- 面板：卡片式新增（系统块/上下文块分按钮）/ 编辑 / 启停 / 排序 / 删除，默认折叠、新增自动展开

### 2.4 文件面板（查看/编辑）

- 文件列表分组：**生效文件（根目录）** 在前，库存按人设各一组在后；库存文件**可直接编辑**（拍板 2026-10-04：绑定该库存的会话即时生效，未绑定会话读根目录默认不受影响）
- 点击查看 + 编辑 + 保存（原子写：临时文件 + rename，UTF-8）
- 选中注入项时显示「注入字数 / 上限 · 仅主会话」；顶部显示最后加载时间（本地化格式）
- 全链路 toast 反馈（成功「已加载/已保存」，失败红字原因）
- 路由侧防路径穿越（resolve 后必须在 workspace 内）；`.current` 有写保护

### 2.5 注入预览（最终形态，历经三次修正）

- **只做全局装配**（无会话作用域卡片，「会话」不出现；全局装配经 M1 探针实测不含对话内容）
- 全量段视角：按装配顺序列出，带「本插件 / 官方」徽标 + 「我的占比」统计
- **本插件段显示文件原文**（拍板：文件里是啥样就显示啥样——不经 mainOnly / 门控 / 截断）；gw-inject 段显示真实注入文本
- **未知来源段（含会话消息投影段）从源头排除**：白名单反向排除（官方实测前缀 `harness:` `deployment:` `app:` `ui:` `tool:` `mcp-` `sandbox:` `approval:` + 本插件前缀），只留「已隐藏非注入段 N ch」数字
- 段点击展开/收起查看完整内容

### 2.6 多魂并行（v0.2.0，/user 会话级人设绑定）

- **拍板**（D8–D11）：命令名 `/user`（已核实与官方 compact/record/feedback/goal 无重名）；子代理继承父会话绑定；绑定人设缺件**留空**（不回退根目录）；绑定**实时读库存**（零快照拷贝）
- 绑定表：`~/.dsh/openclaw/.soul-bindings.json`（`sessionId → 人设名`，原子写，可手改，热加载感知；面板文件列表与 `.current` 一样隐藏）
- 命令（会话里敲）：`/user` 留空 = 查看本会话绑定与库存；`/user <名>` = 绑定；`/user off` = 解绑回全局默认。命令只写绑定表，下一轮请求自然生效，无需重注册
- 注入改道：IDENTITY/USER 两处 section text 回调按 `agent.session.id` 解析（子代理先溯源 `header.parentSession`）；未绑定/无 agent（全局预览）→ 根目录生效文件，单魂行为零变化
- 机制依据（dsh 0.2.0-rc.2 实读）：`commands` 服务 `register({name,description,input,handler})`，handler 收 `{agent, rawInput}`，回 `{kind:'success'|'error', text}`；`agent.session.id` 为持久化 SessionId；`header.parentSession` 记 fork 血脉
- 软降级：`commands` 服务缺失（动态 `ctx.get("commands")` 获取，不进静态 inject）→ 命令不注册，绑定表手改仍生效，单魂无损
- 面板：人设 tab「会话绑定」卡片（**仅绑定清单**：sessionId → 人设名 + 逐条解绑 + 清空全部；不展示活跃对话、不提供绑定/切换入口，拍板 2026-10-04）；绑定/换绑只由会话内 /user 命令产生；删除人设时自动解绑全部指向它的会话并在 toast 提示
- 面板「注入总开关」（拍板 2026-10-04）：**关 = workspace 文件族全部段不注入**——IDENTITY/USER/TOOLS/AGENTS/MEMORY/HEARTBEAT/daily 全停（gw-inject 自由块不受影响，有自己的块级启停；面板编辑不受影响），开 = 恢复；状态存 `~/.dsh/openclaw/.settings.json`，热加载感知，手改也生效；旧键 `personaEnabled` 自动兼容迁移
- 冒烟测试 25 项全过（绑定/继承/缺件留空/预览回退/落盘重载/解绑/删除联动/命令全路径/软降级）

### 2.7 工程行为

- 安装：web profile 走 CLI（file: 真实副本）；desktop profile 走桌面端 UI（CLI 锁定）
- 依赖：`systemPrompt` + `webServer`（host 半）、`slots` + `locale`（client 半）；零 npm 依赖；peer `>=0.1.2-rc.1` 单版本通吃
- 卸载：`dsh plugin remove` 即干净；数据目录 `~/.dsh/openclaw/` 保留（建议 git 管理）
- 日志走 `ctx.logger`，无落盘日志；排障看 dsh 启动日志

## 四、已知边界与代价

1. **agent 写记忆靠协议驱动**：插件只负责「读入」，不驱动 agent 写 MEMORY/daily——写入行为由 `openclaw/AGENTS.md` 里的协议约定（**协议内容由用户自己撰写**，拍板：seed 不内置）
2. **演化人设的存档路径**：agent 对话中改了 IDENTITY/USER，改动留在根目录；要存档进库存用「新建人设（从当前拷贝）」；直接切换人设时若根目录与旧库存有分歧会保留库存版本并警告
3. **web + desktop 双开共享数据目录**：两端同时运行时，人设切换/文件编辑互相可见（watch 保证最终一致），高并发写可能竞态
4. **MEMORY/HEARTBEAT 在真实会话中的截断/门控形态与预览原文不同**：预览是文件原文，注入时有上限截断与门控——两者语义不同属预期行为
5. **预览白名单**：将来 dsh 官方若新增未知前缀的段名，会被误隐藏（错误方向安全：宁少显示不泄露）；届时扩充 `KNOWN_SAFE_RE` 即可
6. **预览不反映会话绑定**：预览是全局装配（拍板过），绑定会话实际看到的库存人设不出现在预览里
7. **绑定表随会话累积**：会话不会自己消失，绑定条目只增不减（除非解绑/清空/删人设联动）；量大时面板「清空全部」或手改 `.soul-bindings.json`
8. **/user 命令依赖 commands 服务**：headless 等无该服务的环境软降级——命令不存在，注入照常
9. **多级子代理绑定断链**：绑定继承（D9）只溯源一级 `parentSession`；孙代理（delegationDepth ≥ 2）查不到顶层绑定会回落全局默认。dsh 常规用法 delegationDepth ≤ 1，影响面小；如需多级继承需引入谱系解析（暂不做）
10. **绑定表残留**：会话删除后绑定条目残留（面板「历史绑定」可见、可解绑/清空），无自动 TTL

## 五、后期需求

- **心跳定时唤醒**（OpenClaw 式）：到点自动触发 HEARTBEAT.md 任务流，让 daily → MEMORY 的整理不依赖用户主动开对话。dsh 有 dsh-schedule 定时服务可承载；涉及唤醒哪个会话、注入什么、与多魂绑定如何配合，属架构级改动，实施前需设计拍板。AGENTS.md 的心跳协议已预埋，功能就绪即生效

## 六、明确不做（YAGNI）

- 项目级 openclaw/ 覆盖层
- slash 命令组（面板已覆盖；会话级切魂只有 /user 一条，见 §2.6）
- 历史备份 / diff / 钉住（防手滑靠用户对 openclaw/ 自行 git 管理）
- 记忆检索 / embedding / 自动合并（文件就是真相；量级触顶再评估）
- markdown 渲染、跨机同步、模型可调用的人设切换工具
